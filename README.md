# 🐍 Python Basics

A collection of beginner-friendly Python programs created while learning and practicing core Python concepts. This repository covers fundamental programming topics such as variables, loops, functions, conditionals, file handling, object-oriented programming, searching algorithms, matrices, and small interactive projects.

## 📚 Topics Covered

- Variables & Data Types
- Input & Output
- Conditional Statements
- Loops
- Functions
- Lists & Dictionaries
- File Handling
- Object-Oriented Programming (Classes & Constructors)
- Matrix Operations (2D Lists)
- Searching Algorithms
- Pattern Printing
- Mini Python Projects

## 🚀 Getting Started

1. Clone this repository:

```bash
git clone https://github.com/your-username/python-basics.git
```

2. Navigate to the project folder:

```bash
cd python-basics
```

3. Run any Python file:

```bash
python filename.py
```
